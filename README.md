# Codeum

Среда разработки для телефона: редактор с панелью символов, настоящий Linux-терминал,
16 языков, GitHub, ИИ-ассистент и виджет «Код дня» на рабочий стол.

## Установка на телефон

1. Скопируй `app/build/outputs/apk/debug/app-debug.apk` на телефон и открой его.
2. Разреши установку из этого источника («Неизвестные приложения»).
3. Android может предупредить, что приложение «создано для старой версии Android» — это ожидаемо (см. ниже), нажми «Всё равно установить».

Или по USB (включи «Отладку по USB» в настройках разработчика):

```
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Выпуск новой версии (GitHub Releases)

Приложение само проверяет последний релиз репозитория `UPDATE_REPO`
(константа в `app/src/main/assets/www/index.html`) и показывает на главном экране
кнопку «Обновить», а стрелка рядом раскрывает «Что нового» — это текст описания релиза.

1. Подними версию в `gradle.properties`: `codeumVersion=1.0.1`.
2. Собери: `gradlew assembleRelease` → `app/build/outputs/apk/release/codeum-v1.0.1.apk`.
3. На GitHub: Releases → Draft a new release → тег **`v1.0.1`** (с буквой v, как в версии).
4. В описание напиши, что нового. Поддерживается простая разметка: `## заголовок`, `- пункт`, `**жирный**`, `` `код` ``.
5. Прикрепи файл `codeum-v1.0.1.apk` и опубликуй (не как pre-release/draft — API отдаёт только «latest»).

Данные при обновлении не теряются, **если APK подписан тем же ключом** (`keystore/`).
Папка `keystore/` не попадает в git — сделай её резервную копию. Если ключ потерять,
обновить уже установленное приложение будет невозможно: только удалить и поставить заново (с потерей данных).

## Сборка

Нужны JDK 17+ и Android SDK (путь — в `local.properties`).

```
set JAVA_HOME=C:\Program Files\Android\openjdk\jdk-21.0.8
gradlew assembleDebug
```

Проект открывается в Android Studio как обычный Gradle-проект.

## Как устроено

| Часть | Где |
|---|---|
| Интерфейс (HTML/JS, работает и в браузере) | `app/src/main/assets/www/index.html` |
| WebView, выбор файлов и папок, кнопка «назад» | `MainActivity.kt` |
| Мост JS ↔ Android (`window.CodeumNative`) | `NativeBridge.kt` |
| Linux-окружение: proot + Alpine, установка языков через `apk` | `LinuxEnv.kt` |
| Виджет «Код дня» 4×2 и 2×2, смена по расписанию | `Widgets.kt`, `res/layout/widget_code*.xml` |
| Данные виджета (генерируются из index.html) | `node tools/gen-snippets.js` → `assets/snippets.json` |

При первой установке любого языка приложение скачивает:
- `proot` из репозитория Termux (~1 МБ);
- Alpine Linux minirootfs (~4 МБ);
- затем сам язык пакетом Alpine (`python3`, `build-base`, `go`, `rust`, `openjdk21-jdk`, `dotnet8-sdk`…).

## Ограничения версии 0.3

- **targetSdk 28** — осознанно, как у Termux: с targetSdk 29+ Android запрещает запускать
  скачанные компиляторы. Поэтому APK распространяется напрямую или через F-Droid, не через Google Play.
- Swift и Dart пока недоступны (нет сборок под Alpine/musl).
- Терминал без PTY: обычные команды, компиляция и ввод для программ (`input()`, `scanf`) работают,
  но полноэкранные программы (vim, htop) и SSH с вводом пароля — нет. Это следующий шаг.
- «Открыть папку» читает только текстовые файлы (до 400 штук, до 2 МБ каждый).
