Нет компьютера, а учиться программировать хочется? Codeum превращает телефон в нормальное
рабочее место: удобный редактор, настоящий терминал и шестнадцать языков программирования,
которые ставятся одной кнопкой. Никаких костылей и эмуляторов клавиатуры — всё уже внутри.

## Скачать

Последняя версия всегда здесь: **[Releases → codeum-vX.X.X.apk](https://github.com/himsson/Codeum/releases/latest)**

### Как установить

1. Открой ссылку выше с телефона и скачай файл `codeum-v….apk`.
2. Нажми на скачанный файл.
3. Телефон спросит, можно ли устанавливать приложения из этого источника — разреши.
4. Если появится надпись «Приложение создано для старой версии Android» — нажми **«Всё равно установить»**.
   Это нормально, почему так — написано ниже в вопросах.

Приложению нужен Android 8.0 или новее.

## Что умеет

- **Редактор кода** с подсветкой, номерами строк и вкладками. Над клавиатурой — панель со скобками,
  кавычками и стрелками, чтобы не искать `{ }` по трём раскладкам.
- **Кнопка Run.** Написал код — нажал — увидел результат. Если программа что-то спрашивает
  (`input()`, `scanf`), ответ вводишь прямо в терминале.
- **Настоящий терминал.** Внутри работает Linux, поэтому команды настоящие. При первом запуске
  выбираешь, какой терминал тебе привычнее — **Windows**, **Linux** или **macOS** — и Codeum
  подстраивает под него внешний вид и команды (`dir` и `cls` для Windows, `ls` и `clear` для остальных).
- **Проекты и папки.** Создавай файлы с нужным расширением, раскладывай по папкам, открывай файлы
  и целые папки с телефона.
- **GitHub.** Подключи аккаунт — и клонируй свои репозитории, правь их и отправляй изменения.
- **ИИ-помощник.** Подключи свой ключ Claude, OpenAI или Gemini: он объяснит код, найдёт ошибку,
  допишет комментарии.
- **Виджет «Код дня»** на рабочий стол. Раз в день (или раз в пять часов) — новый кусочек кода
  и простое объяснение, что он делает. Учишься, даже не открывая приложение.
- **Восемь тем**: Midnight, Tokyo Night, Dracula, Catppuccin, Nord, Monokai, Solarized и светлая Paper.
- **Обновления в один тап.** Когда выходит новая версия, на главном экране появляется кнопка
  «Обновить», а рядом — список того, что изменилось. Твои проекты и настройки при обновлении
  никуда не деваются.

## Языки

Ставятся во вкладке «Языки». Качаешь только то, что нужно.

| Язык | Размер | | Язык | Размер |
|---|---|---|---|---|
| JavaScript | встроен | | Go | ~230 МБ |
| Python | ~45 МБ | | Rust | ~380 МБ |
| TypeScript | ~60 МБ | | PHP | ~15 МБ |
| C | ~150 МБ | | Ruby | ~25 МБ |
| C++ | ~150 МБ | | Lua | ~1 МБ |
| C# | ~420 МБ | | Bash | ~2 МБ |
| Java | ~190 МБ | | Swift | скоро |
| Kotlin | ~260 МБ | | Dart | скоро |

C и C++ используют общий компилятор, поэтому вместе занимают столько же, сколько один.

## Вопросы

**Почему приложения нет в Google Play?**
Google Play не пропускает приложения, которые скачивают и запускают компиляторы. Codeum без этого
не может — иначе код было бы нечем запускать. По той же причине так распространяется Termux.

**Почему телефон пишет, что приложение «для старой версии Android»?**
Это следствие того же ограничения: новые правила Android запрещают запускать скачанные программы,
а Codeum именно этим и занимается. На работу и безопасность телефона это не влияет.

**Нужен ли интернет?**
Только чтобы скачать языки, обновления и пользоваться GitHub или ИИ. Писать и запускать код
на уже установленных языках можно без интернета.

**Сколько места нужно?**
Само приложение — около 2 МБ. Остальное зависит от языков: Python и JavaScript — это совсем немного,
Rust или C# — несколько сотен мегабайт. Скачивать тяжёлые языки лучше по Wi-Fi.

**Куда пишется мой ключ от ИИ или токен GitHub?**
Только в память телефона. Никуда, кроме самого GitHub и выбранного сервиса ИИ, они не отправляются.

**Нашёл ошибку или есть идея.**
Напиши в [Issues](https://github.com/himsson/Codeum/issues) — что сделал, что ожидал и что получилось.
Скриншот очень помогает.
