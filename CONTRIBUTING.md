# Contributing

Codeum is currently developed as a personal project.

If you find a bug or have a feature request, feel free to open an
[Issue](https://github.com/himsson/Codeum/issues).

Before submitting an issue, please check whether it has already been reported.

## What helps the most

- **A clear report.** What you did, what you expected, what happened instead.
  A screenshot or a short screen recording is worth ten paragraphs.
- **The version and the phone.** The version is at the bottom of Settings, for example `1.0.3`.
  Bugs often depend on the Android version and on the processor.
- **A crash report.** If the app closed by itself, the next launch offers to report it.
  That report already contains the error text, the version and the device.
- **Testing a new release.** New versions are tested on an emulator; real phones are more
  interesting. If something broke after an update, say so — that is the most useful report there is.

## About code

The source code is published for viewing, not for reuse: see [LICENSE](LICENSE).
Because of that, pull requests with new features are not accepted. Corrections to the
documentation — a typo, a wrong command, a broken link — are welcome.

## Translations

The interface lives in `app/src/main/assets/www/i18n/`, one file per language, plain key–value pairs.
If a phrase in your language sounds wrong or machine-made, open an issue with the key and a better
wording — that kind of report is easy to act on and improves the app for everyone who speaks it.
